# Dreamcatcher

A 2D pixel-art platformer about chasing dreams — and discovering the small
moments were the point all along. See [DESIGN.md](DESIGN.md) for the full
game design document.

## Play

Deployed automatically to GitHub Pages on every push to `main`.

## Develop

```bash
npm install
npm run dev
```

Then open the printed localhost URL. `npm run build` produces the production
bundle in `dist/`.
