# `small` font — complete 5×7 glyph set

Format matches `pixelart.js`: `#` ink, `.` empty. Each glyph is exactly 5 wide × 7 tall; advance = 6 px (1 px gap). Copy into `src/ui/fonts/small.js` as `export default { 'A': [...], ... }`.

## Deriving the other two fonts
- **`body` (7×9, 2-px descender):** start from `small`, widen bowls by 1 px on each side, add rounded corners (drop the corner pixel of every square 2×2 corner), add lowercase with x-height 6 and descenders on `g j p q y`. Stroke stays 1 px.
- **`display` (12×16, 2-px stroke):** scale `small` 2× (each pixel → 2×2), then add 2-px slab serifs at the foot of `I L T E F` and the stems of `M N H`, and 1 px of `o` shading along the bottom/right of every stroke for the slab shadow.
